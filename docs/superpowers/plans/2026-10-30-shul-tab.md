# Shul Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `shul` scene that shows Bnai Yeshurun's weekly davening chart on weekdays and the bulletin's Shabbat Times on Shabbat, fetched by the server on Friday afternoons and on demand.

**Architecture:** `server.py` gains a stdlib PDF text reader, a Shabbat Times parser, link pickers for three ShulCloud pages, and a `shul` source that downloads only changed files into `shul/` and puts their metadata and the parsed times in `/api/state`. `index.html` gains the scene and two panels. `update-shul.bat/.sh` trigger the same fetch now.

**Tech Stack:** Python 3 standard library (`zlib`, `re`, `html.parser`, `urllib`), plain JS/CSS in `index.html`, stdlib `unittest`.

**Spec:** `docs/superpowers/specs/2026-10-30-shul-tab-design.md`

## Global Constraints

- Server stays Python standard library only; nothing to pip install.
- Every shul request sends `User-Agent: ShabbatDisplay/1.0 (personal home display)` (constant `SHUL_UA`), never the browser-like `UA`. A refusal is a failure, not something to retry with other headers.
- Per run: the 3 pages plus only files whose URL changed (≤ 4). Automatic runs only on Fridays from 12:00 until candle lighting, at most hourly, plus once at start if nothing is stored.
- Shabbat view never shows guessed times: unparseable box → Hebcal candles/havdalah + "Shul times unavailable — see bulletin".
- Test fixtures are made up (synthetic HTML and a synthetic PDF from `tests/pdfmaker.py`), never copies of the shul's pages or bulletin.

**Interfaces:**
- Produces: `pdf_pages(data: bytes) -> list[list[tuple[float, float, str]]]` — per page, in page order, text runs `(x, y, text)` in PDF points (y up). Raises `ValueError` if the file has no readable pages.
- Produces (test helper): `tests/pdfmaker.make_pdf(pages: list[list[tuple[float, float, str]]]) -> bytes` — a FlateDecoded PDF in Word's style: one content stream per page, `BT … /Fx size Tf 1 0 0 1 x y Tm [(…)] TJ ET`; ASCII runs use a WinAnsi font with literal strings; runs with non-ASCII (Hebrew) use a Type0 font with 2-byte hex glyph codes and a `/ToUnicode` CMap (`beginbfchar`), and Hebrew is placed one character per run, as Word does.

Approach (proven on the real 24 Oct bulletin): collect `N 0 obj … endobj`; pages are objects matching `/Type\s*/Page[^s]` in object order; for each page read its `/Font` dict (inline `<<…>>`) and `/Contents` (single ref or array); decode Flate streams; tokenize content (literal strings with escapes incl. octal, hex strings, arrays, numbers, names, operators); track `Tf`, `Tm`, `Td`, `TD`, `T*`, `BT`; on `Tj`/`TJ` decode with the font's ToUnicode map (code width from the map's source codes) or cp1252; a TJ kerning number below −200 becomes a space. Keep whitespace-only runs (Hebrew word spaces are separate runs).

### Task 2: Shabbat Times parser

**Files:** Modify `server.py`, `tests/test_shul.py`

**Interfaces:**
- Consumes: `pdf_pages`.
- Produces: `shabbat_times(pages) -> dict | None` = `{"rows": [{"label": str, "time": str, "he": str}], "notes": [str]}`, rows top to bottom; `None` when no valid box.

Algorithm (fixes the layout facts measured on the real bulletin: label column x≈20–175, time column x≈180–215, Hebrew x≈230 to the box edge, multi-line labels ±7 pt from their time):
1. Find the page and run whose text is `Shabbat Times`. The box is the runs below it whose x is left of the column gap: the box's right edge is the first x > 280 where no run in the box's y-range starts within the next 8 pt.
2. Stop at the first line whose text starts with `Please park`, or at a vertical gap > 25 pt between consecutive lines.
3. Group runs into lines by y (±2 pt). A line's time-column runs (180 ≤ x < 228), joined without spaces and normalized (`9:5`+`8 am` → `9:58 am`), anchor a row only if they fully match `^\d{1,2}:\d{2} ?[ap]m$`.
4. Each label-column (x < 180) line and each Hebrew line (x ≥ 228, characters joined in descending x so RTL reads correctly, whitespace collapsed) goes to the nearest anchor within 10 pt; label lines join with a space. Lines with no anchor within 10 pt become `notes` (text joined in x order, whitespace collapsed).
5. Valid only if some row label contains `Candle` and some row label matches `Shabbat Ends|Yom Tov Ends|Y"T Ends|Ends`; else `None`.

### Task 4: The `shul` source, files and routes

**Files:** Modify `server.py`, `tests/test_shul.py`, `.gitignore` (`shul/`); Create `update-shul.bat`, `update-shul.sh` (LF)

**Interfaces:**
- Consumes: Tasks 1–3.
- Produces:
  - `SHUL_DIR = os.path.join(HERE, "shul")`
  - `shul_get(url: str, limit=20_000_000) -> bytes` (SHUL_UA, `Accept: text/html,*/*`, timeout 20).
  - `shul_due(n: datetime, cur: dict | None, candles: datetime | None) -> bool` — True if `cur` is None or any file in `cur` is missing on disk; or if `n` is a Friday, `n.time() >= 12:00`, `n < (candles or n.replace(hour=18, minute=0))`, and `cur["bulletin"]["shabbat"] != upcoming_shabbat(n.date()).isoformat()`.
  - `fetch_shul(force=False) -> dict` — returns `store.get("shul")` untouched when not `force` and not `shul_due(now(), cur, todays_candles())`. Otherwise reads the three pages, downloads each chosen URL whose URL differs from `cur` or whose file is missing, writes to `SHUL_DIR` atomically (`.tmp` then `os.replace`) under the URL's basename, and returns:
    `{"chart": {"file", "url", "week_of"}, "bulletin": {"file", "url", "shabbat", "times"}, "calendars": [{"file", "url"}], "checked": iso}` (`week_of`/`shabbat` from `file_date`, ISO or None; `times` = `shabbat_times(pdf_pages(...))` or None, re-parsed only when the bulletin file changed). An item the pages don't offer keeps its previous value. Any page fetch error raises (the source loop records it and keeps the old value).
  - `todays_candles() -> datetime | None` from `store.get("calendar")` items with `category == "candles"` dated today.
  - SOURCES entry `("shul", fetch_shul, 3600)`.
  - Route `GET /shul/<name>`: `name` must fully match `[A-Za-z0-9._-]+`, not start with `.`, and exist in `SHUL_DIR`; type by extension (`.png` image/png, `.jpg/.jpeg` image/jpeg, `.pdf` application/pdf); else 404.
  - Route `GET /api/shul-update` (only when `self.client_address[0] == "127.0.0.1"`, else 403): runs `fetch_shul(force=True)`, `store.set("shul", …)`, returns `{"ok": true, "summary": str}` or 503 `{"ok": false, "error": str}`.
  - `python server.py --update-shul`: GET `http://127.0.0.1:<port>/api/shul-update`; if the server isn't running, run `fetch_shul(force=True)` in-process and `store.set`. Prints `Davening: <file> · Bulletin: <file> (<shabbat or "no date">) · Calendar: <files>` and `Shabbat times: <n> rows` or `Shabbat times: not readable`.
  - `update-shul.bat` / `.sh`: run `server.py --update-shul` with the same Python lookup as `check-feeds.bat` / `.sh`, then pause (bat).
